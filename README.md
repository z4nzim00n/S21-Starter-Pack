## 🎯 Для кого этот гайд?

Для студентов Школы 21, которые прошли бассейн и перешли на основной этап обучения.

Гайд поможет настроить рабочее окружение на Windows, чтобы меньше времени тратить на конфигурацию терминала и больше — на решение задач.

## 🛠 Что будем настраивать

- **WSL** — Linux-окружение внутри Windows.
- **SSH-ключи** — отдельная настройка доступа к GitLab для Windows и WSL.
- **Шрифты** — шрифты для корректного отображения символов в терминале.
- **WezTerm** — настраиваемый терминал с готовой конфигурацией.
- **Fish** — альтернативная командная оболочка.
- **Starship** — информативная строка приглашения командной оболочки (prompt).
- **Zoxide и Fzf** — инструменты для навигации по каталогам и поиска.
- **Eza, Bat и Ripgrep** — инструменты для просмотра файлов, чтения текста и поиска по содержимому.
- **Fisher** — менеджер плагинов для Fish.
- **Pokemon-colorscripts** — декоративные изображения покемонов в терминале.
- **Готовый конфиг Fish** — настройки, чтобы не собирать окружение вручную.

## ✨ Что получится в итоге

После выполнения инструкций у тебя будет:

- Linux-окружение через WSL;
- настроенный терминал WezTerm;
- Fish вместо стандартной оболочки Bash;
- информативный prompt через Starship;
- удобные команды для навигации и работы с файлами;
- готовое окружение для учёбы в Школе 21.
