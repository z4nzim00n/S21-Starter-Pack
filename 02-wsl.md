## Установка WSL

Открываем **PowerShell от имени администратора**.

Пишем:

```powershell
wsl --install
```

После этого перезагружаем компьютер.


![Установка WSL](assets/2.1%20wsl%20install.png)


---

## Первый запуск

После перезагрузки открываем терминал cmd или powershell и пишем:
```powershell
wsl --set-default Ubuntu
```
```powershell
wsl
```

У тебя откроется Ubuntu.

Она попросит создать пользователя.

После этого нужно будет придумать пароль.

**Важно:**

Когда вводишь пароль, ничего не происходит.

Звёздочек тоже нет.

Это нормально.

## Ставим инструменты для S21

Обновляем список пакетов:

```bash
sudo apt update
```

Ставим всё необходимое:

```bash
sudo apt install git gcc make valgrind -y
```


Проверяем установку:

```bash
gcc --version
```

```bash
make --version
```

```bash
valgrind --version
```


Если команды работают — поздравляю, у тебя теперь почти бассейн дома.

![gccs](assets/2.2%20gccs.png)

## SSH ключ (делаем ещё раз, но уже в WSL)

Если ты уже сделал SSH ключ в прошлом пункте — молодец.

Но есть один важный момент:

**Windows и WSL — это разные системы.**

То есть корневые папки у винды и линукса отличаются. И ssh для виртуального линукса нужен новый.

Повторяем ssh-keygen, и всё.

Копируем его в GitLab.


После этого команды:

```bash
git clone
git add
git commit -m "commit_message"
git push
```

будут работать прямо из Ubuntu.

# Настройка прав для Windows-дисков (важно для Git)

WSL и Windows используют разные файловые системы.

Если работать с проектами внутри Windows-папок:

```
/mnt/c
/mnt/d
/mnt/e
```

могут возникнуть проблемы с Linux-правами.

Например:

- Git не сможет создать репозиторий;
- появятся ошибки `chmod`;
- некоторые Linux-инструменты будут работать неправильно.

Чтобы этого избежать, включаем поддержку Linux-прав для Windows-дисков.

---

## Открываем файл wsl.conf

Его можно открыть двумя способами.

### Через проводник Windows:

Переходим:

```
\\wsl.localhost\Ubuntu\etc
```

Открываем файл:

```
wsl.conf
```

---

### Через Linux:

В терминале:

```bash
sudo nano /etc/wsl.conf
```

---

## Настраиваем wsl.conf

Добавляем:

```ini
[automount]
options = "metadata"
```

В итоге весь файл должен выглядеть примерно так:

```ini
[boot]
systemd=true

[user]
default=ВАШ_ПОЛЬЗОВАТЕЛЬ

[automount]
options = "metadata"
```

Где:

```
ВАШ_ПОЛЬЗОВАТЕЛЬ
```

— имя пользователя, которое вы создали при первом запуске Ubuntu.

Узнать его можно командой:

```bash
whoami
```

---

## Перезапускаем WSL

Закрываем Ubuntu.

Открываем PowerShell от имени администратора:

```powershell
wsl --shutdown
```

После этого снова запускаем:

```powershell
wsl
```

---

Теперь Git и другие Linux-инструменты смогут нормально работать с папками Windows.

---

## Проверка

Переходим в любую Windows-папку:

```bash
cd /mnt/c/Users
```

Создаём тестовый файл:

```bash
touch test.txt
```

Если файл появился — всё работает.
