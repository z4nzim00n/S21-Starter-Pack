## Установка WSL

Открываем **PowerShell от имени администратора**.

Пишем:

```powershell
wsl --install
```

После этого перезагружаем компьютер.


![Установка WSL](assets/2.1%20wsl%20install.png)


---

## Первый запуск

После перезагрузки открываем терминал cmd или powershell и пишем:
```powershell
wsl --set-default Ubuntu
```
```powershell
wsl
```

У тебя откроется Ubuntu.

Она попросит создать пользователя.

После этого нужно будет придумать пароль.

**Важно:**

Когда вводишь пароль, ничего не происходит.

Звёздочек тоже нет.

Это нормально.

## Ставим инструменты для S21

Обновляем список пакетов:

```bash
sudo apt update
```

Ставим всё необходимое:

```bash
sudo apt install git gcc make valgrind -y
```


Проверяем установку:

```bash
gcc --version
```

```bash
make --version
```

```bash
valgrind --version
```


Если команды работают — поздравляю, у тебя теперь почти бассейн дома.

![gccs](assets/2.2%20gccs.png)

## SSH ключ (делаем ещё раз, но уже в WSL)

Если ты уже сделал SSH ключ в прошлом пункте — молодец.

Но есть один важный момент:

**Windows и WSL — это разные системы.**

То есть корневые папки у винды и линукса отличаются. И ssh для виртуального линукса нужен новый.

Повторяем ssh-keygen, и всё.

Копируем его в GitLab.


После этого команды:

```bash
git clone
git add
git commit -m "commit_message"
git push
```

будут работать прямо из Ubuntu.
